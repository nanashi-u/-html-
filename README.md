# 公众号草稿导出 / 导入

在微信公众号草稿编辑页，一键完成两件事：

- **草稿 → HTML**：导出单文件 HTML（图片内嵌）、导出 ZIP、或直接复制 HTML 代码；
- **HTML → 草稿**：把一段 HTML 粘贴回编辑器，插入或替换全文。

## 安装

1. 解压本文件夹。
2. Chrome 打开 `chrome://extensions/`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本文件夹（有 `manifest.json` 的那层）。
4. 列表中出现「公众号草稿导出」即安装成功。

> Edge 用户：`edge://extensions/`，步骤相同。

## 使用

登录 `mp.weixin.qq.com`，打开草稿箱里任意一篇草稿进入编辑页，右下角会出现三个按钮：

| 按钮 | 作用 | 产物 |
| --- | --- | --- |
| **导出 HTML** | 单文件网页，图片以 base64 内嵌 | `草稿标题.html` |
| **复制代码** | 完整 HTML 源码写入剪贴板 | 直接粘贴到任何编辑器 |
| **导出 ZIP** | 网页 + 原始图片文件 | `草稿标题_草稿导出.zip` |
| **导入 HTML** | 粘贴 HTML，插入或替换正文 | 直接改写编辑器 |

### 导出

点「导出 HTML」，等几秒，浏览器自动下载 `.html` 文件。它是一个**独立文件**：双击用浏览器打开就是排版好的文章，图片、配色、段落都在，发给别人也不会丢图。

需要原始图片素材（比如再上传到别处），用「导出 ZIP」，解压得到 `index.html` + `images/`。

### 导入

点「导入 HTML」，把 HTML 代码粘进弹窗：

- **插入到光标处**：在当前位置插入；
- **替换全文**：清空正文后整篇替换（谨慎使用）。

图片说明：HTML 里的图片如果是微信 CDN 链接，可以直接用；如果是 `data:` 内嵌图，编辑器可能显示但保存时需注意；如果是外链图片，发表后可能失效。最稳妥的是先用导出功能得到微信 CDN 链接的版本，再导入。

## 兼容性

- 适配新版 ProseMirror 编辑器，也兼容旧版 UEditor（iframe）；
- 任意排版的草稿都能导出：文字、图片、section 背景块、表格等，原样保留；
- 只导出**当前打开的一篇**草稿，不支持批量。

## 常见问题

**按钮没出现？**
确认地址栏是 `...appmsg_edit...` 的编辑页，正文编辑器已加载；刷新页面再试。

**点击后没反应？**
检查 Chrome 是否拦截下载（地址栏右侧的下载图标），或到 `chrome://downloads` 查看。

**图片没下载/没内嵌？**
个别图片可能有防盗链限制，导出 HTML 时会保留原微信链接，不影响阅读。

**导入后排版乱了？**
编辑器的清洗规则可能调整部分样式；建议导入后先检查一遍再保存。

## 隐私

- 扩展没有服务器，不上传任何内容；
- 只访问 `mp.weixin.qq.com`（读写草稿）和 `mmbiz.qpic.cn`（下载图片）；
- 所有文件只保存在本机。

## 卸载

`chrome://extensions/` → 找到「公众号草稿导出」→ 移除。

## 分发

把整个文件夹压缩成 zip 发给朋友，对方解压后按「安装」步骤加载即可。
